# Ελληνικό Λεξιλόγιο / Greek Vocabulary 🇬🇷

A personal record of Greek words I'm learning, maintained by Zorio 🦊.

## How it's organized

- Words are listed **in the order they were added** — no grouping by date.
- Each file holds a **maximum of 100 words**:
  - `vocabulary/001.md` → words 1–100
  - `vocabulary/002.md` → words 101–200
  - and so on…

## Entry format

Every word is recorded like this:

```markdown
### λέξη
- Transliteration: léxi
- Pronunciation: /IPA/
- Part of speech: noun / verb / adjective ...
- Meaning: English meaning
```

## Workflow

Tell Zorio which Greek words you learned. Zorio looks up each word's transliteration, pronunciation, and meaning, appends them in order to the current vocabulary file (rolling to a new file at 100 words), and pushes the update to GitHub.
